# 📻 PREGÓN 95.7 FM - App Oficial

Aplicación Web Progresiva (PWA) oficial de la emisora comunitaria **Pregón 95.7 FM**, transmitiendo desde Mucutuy, estado Mérida, para todos los Pueblos del Sur y el mundo.

## 🚀 Características Principales

* **🎧 Radio en Vivo:** Streaming de audio continuo optimizado con animaciones reactivas en tiempo real.
* **📺 Televisión y Video:** Reproductor HLS integrado para canales en vivo y señal de YouTube.
* **⚽ Deportes en Vivo:** Integración con la API de ESPN para mostrar los resultados de las ligas de fútbol en tiempo real.
* **💬 Chat Comunitario:** Sala de chat global en vivo utilizando Firebase Realtime Database.
* **⛅ Clima y Satélite:** Widget del clima local de Mucutuy y mapa interactivo.
* **📱 PWA (Progressive Web App):** Instalable en teléfonos móviles (iOS y Android) para funcionar como una app nativa con soporte para modo offline básico.

## 🛠️ Tecnologías Utilizadas

Este proyecto está construido en una arquitectura *Single-File Component* orientada al rendimiento, utilizando:

* **Frontend:** React.js 18 (vía CDN), Babel Standalone.
* **Estilos:** Tailwind CSS.
* **Backend y Autenticación:** Firebase (Auth & Realtime Database).
* **Streaming:** Hls.js para video, Zeno.fm para audio y metadatos.
* **APIs Externas:** Open-Meteo (Clima), ESPN (Deportes).
* **Despliegue:** GitHub Pages con Custom Domain.
